# Araştırma defteri kimliği

Kurulum: `cd _kimlik && npm install` (yazı tipleri @fontsource paketlerinden gelir).

- `defter_reel2.py`: Reels şablonu (ginepig örneği). `python3 defter_reel2.py [stills]` → out/reel/sessiz.mp4
- `sayfa_tipleri.py`: 5 carousel sayfa tipi (deney, büyük rakam, karşılaştırma, yapışkan not, kontrol listesi).

Yazı tipleri: Instrument Sans (başlık/metin), Geist Mono (etiket), Kalam (el yazısı).
